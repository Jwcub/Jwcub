## Featured Projects

### 📚 Bibbla – School Library Management System

A platform for students to search, borrow, and reserve books, with a dedicated admin page that gives librarians an overview of loans and reservations.

- **Tech:** C#, ASP.NET Core, Razor Pages, EF Core, SQLite, Tailwind CSS, Azure
- **Focus:** Security and usability (authentication, hashed passwords, role-based access control)
- **Links:** [Live demo](https://bibbla-a4e4e0afe8c6embr.swedencentral-01.azurewebsites.net/) | [Source Code & Test Accounts](https://github.com/Jwcub/Bibbla)

### 🍽️ PrettyDecent – Fullstack Restaurant Web App

A restaurant website where visitors can browse the menu, book tables, and send messages, with a protected admin view for managing the menu, bookings, and messages.

- **Tech:** Angular, TypeScript, Node.js, Express, MongoDB, JWT
- **Focus:** Custom REST API, protected endpoints, and frontend-backend communication
- **Links:** [Live Demo](https://prettydecent.onrender.com/menu) | [Frontend Repo](https://github.com/Jwcub/PrettyDecent_frontend) | [Backend Repo](https://github.com/Jwcub/PrettyDecent_backend)

### 🎓 Academia – Course & Schedule Planner

A tool for students to search, filter, and organize courses into a custom schedule that persists between sessions.

- **Tech:** Angular, TypeScript, Angular Material
- **Focus:** Components and services, pagination, and responsive UI with dark and light mode
- **Links:** [Live Demo](https://academiauni.netlify.app/) | [Source Code](https://github.com/Jwcub/Academia)
